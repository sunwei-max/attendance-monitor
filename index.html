高三16班腾讯会议考勤监控

用腾讯会议 API 自动比对班级花名册，实时显示在线 / 缺席名单，支持复制考勤通报、标记请假。

⚠️ 本页托管于 GitHub Pages（纯静态），不能实时考勤——实时拉取需要后端服务。
看实时考勤请点下面「打开考勤网页」，在手机浏览器中打开；若微信拦截，点右上角「…」→「在浏览器打开」即可。
🟢 打开考勤网页（完整功能，建议用浏览器） 📦 查看源码仓库 📘 复刻指南

功能一览

  • 实时在线 / 缺席 / 待核对名单 + 出勤率
  • 一键复制考勤通报（应到/实到/缺席 + 名单 + 时间）
  • 缺席学生可标记请假（6 小时有效，上线自动清除）
  • 三级额度保护，纯手动刷新，额度几乎用不完
  • 额度耗尽时可用会议导出 xlsx 离线分析

部署：FastAPI 后端 + 腾讯会议开放平台 MCP。本静态页仅作入口与说明。
